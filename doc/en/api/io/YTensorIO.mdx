# YTensorIO

`yt::io::YTensorIO` reads and transactionally writes `.yt` tensor files.

## Open And Close

```cpp
yt::io::YTensorIO io;
if (!io.open("model.yt", yt::io::Write)) return false;
if (!io.save(tensor, "weight")) return false; // staged, not committed yet
if (!io.close()) return false;                // durable commit result
```

```cpp
bool open(const std::string& fileName, int fileMode = yt::io::Read);
bool close();
```

The modes are `yt::io::Read`, `yt::io::Write`, and `yt::io::Append`. A write session keeps the original target until `close()` has written and flushed a complete same-directory temporary file and replaced the target. Implementations that cannot rename over an existing file use a same-directory backup/restore transaction. Any staging or recoverable commit failure makes `close()` return `false` and preserves the previous committed file. The `noexcept` destructor closes the session but cannot report success, so explicit `close()` is required when commit status matters.

## Save

```cpp
bool save(const yt::YTensorBase& tensor, const std::string& name);

template<typename T, int dim>
bool save(const yt::YTensor<T, dim>& tensor, const std::string& name);
```

`save()` serializes and stages one Strided tensor. Returning `true` means staging succeeded; only `close()` reports durable success. Saving the same name replaces that staged record. Compression is selected by the global `yt::io::compressMethod` setting.

Non-POD dtypes require registered `serialize` and `deserialize` callbacks. Map payloads are variable-length; serialized values are not limited to `sizeof(T)`.

## Load

```cpp
bool load(yt::YTensorBase& tensor, const std::string& name = "");

template<typename T, int dim>
bool load(yt::YTensor<T, dim>& tensor, const std::string& name = "");
```

Load validates metadata, ranges, payload sizes, dtype lifecycle information, and serialized values before replacing the destination. Failure returns `false` and leaves the destination unchanged. Typed load also validates dtype and rank.

## Convenience Functions

```cpp
bool saveTensorBase(const std::string& fileName, const YTensorBase& tensor,
                    const std::string& name = "");
bool loadTensorBase(const std::string& fileName, YTensorBase& tensor,
                    const std::string& name = "");

template<typename T, int dim>
bool saveTensor(const std::string& fileName, const YTensor<T, dim>& tensor,
                const std::string& name = "");
template<typename T, int dim>
bool loadTensor(const std::string& fileName, YTensor<T, dim>& tensor,
                const std::string& name = "");
```

The save helpers include `open()`, staging, and `close()` in their boolean result.
