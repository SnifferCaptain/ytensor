# Backend System

This page describes matrix-multiplication backend configuration in the `yt::info` namespace.

## `MatmulBackend`

```cpp
enum class MatmulBackend {
    Naive = 0,  // Dependency-free reference implementation
    Eigen = 1,  // Eigen implementation
    YBLAS = 2   // YTensor's BLAS implementation
};
```

## Default Backend Preference

```cpp
static constexpr MatmulBackend defaultMatmulBackend =
#if YT_USE_YBLAS
    MatmulBackend::YBLAS
#elif YT_USE_EIGEN
    MatmulBackend::Eigen
#else
    MatmulBackend::Naive
#endif
;
```

Preference order: YBLAS, then Eigen, then Naive.

## Build Macros

| Macro | Description |
| --- | --- |
| `YT_USE_EIGEN` | Enables the Eigen backend |
| `YT_USE_YBLAS` | Enables the YBLAS backend |
| `YT_USE_AVX2` | Enables the AVX2+FMA physical kernel currently used by YBLAS |

YBLAS currently has an AVX2+FMA physical kernel, so `YT_USE_YBLAS` follows `YT_USE_AVX2` by default.
`YT_USE_AVX2` is detected from the compiler's AVX2 and FMA feature macros. Defining it as `1` without
the matching compiler target is not supported.

A `MatmulBackend` argument expresses a preference. If the requested backend does not support the current dtype or build configuration, YTensor falls back to an available implementation.
