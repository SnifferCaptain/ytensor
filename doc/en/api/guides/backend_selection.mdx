# Backend Selection

This guide helps you choose the most suitable computation backend.

## Available Backends

YTensor supports multiple backends for matrix multiplication:

| Backend | Enum Value | Dependency | Applicable Scenarios |
| --- | --- | --- | --- |
| Naive | `MatmulBackend::Naive` | None | Compatibility first, debugging |
| Eigen | `MatmulBackend::Eigen` | Eigen3 | General high-performance computing |
| YBLAS | `MatmulBackend::YBLAS` | Currently requires an AVX2 + FMA CPU and compiler target | YTensor's FP32/FP16 matrix implementation |

The backend argument is a preference. If the requested backend cannot handle the current dtype or build configuration, YTensor falls back to an available implementation. See [YTensor::matmul](../YTensor/math/matmul.mdx) for layout and dtype behavior.

---

## Automatic Selection

The default backend is automatically selected based on compile-time macros, with priority: **YBLAS > Eigen > Naive**

```cpp
// Definition in ytensor_infos.hpp
static constexpr MatmulBackend defaultMatmulBackend = 
#if YT_USE_YBLAS
    MatmulBackend::YBLAS
#elif YT_USE_EIGEN
    MatmulBackend::Eigen
#else
    MatmulBackend::Naive
#endif
;
```

## Compilation Configuration

### Enabling Eigen

```cmake
# CMakeLists.txt
find_package(Eigen3 REQUIRED)
target_link_libraries(your_target Eigen3::Eigen)
```

Eigen will be automatically detected:
```cpp
#if __has_include(<Eigen/Core>)
    #define YT_USE_EIGEN 1
#endif
```

### Enabling YBLAS

```cmake
# CMakeLists.txt
target_compile_options(your_target PRIVATE -mavx2 -mfma)
```

YBLAS currently has an AVX2+FMA physical kernel. `YT_USE_AVX2` is detected from compiler feature macros,
and `YT_USE_YBLAS` follows that result by default. Defining `YT_USE_AVX2=1` does not enable CPU
instructions by itself; YTensor rejects that configuration unless both compiler features are active.

Define `YT_USE_YBLAS=0` before including YTensor to disable the custom backend while keeping the AVX2
compiler target. Define `YT_USE_AVX2=0` to disable the physical kernels as well.

## Checking Current Backend

```cpp
#include "ytensor_infos.hpp"

void check_backend() {
    #if YT_USE_YBLAS
        std::cout << "Using YBLAS backend" << std::endl;
    #elif YT_USE_EIGEN
        std::cout << "Using Eigen backend" << std::endl;
    #else
        std::cout << "Using Naive backend" << std::endl;
    #endif
}
```
