# 矩阵乘法

本文档介绍 YTensor 的矩阵乘法功能。

---

## matmul()

对张量的最后两个维度执行矩阵乘法，支持批量操作和自动广播。

### 函数签名

```cpp
template <int dim1>
YTensor<T, CONSTEXPR_MAX({dim, dim1, 2})> matmul(
    const YTensor<T, dim1>& other,
    yt::info::MatmulBackend backend = yt::info::defaultMatmulBackend
) const;
```

### 参数说明

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `other` | `const YTensor<T, dim1>&` | - | 右操作数张量 |
| `backend` | `MatmulBackend` | `defaultMatmulBackend` | 矩阵乘法后端偏好；不支持时回退 |

### 核心功能描述

对张量的最后两个维度执行矩阵乘法。
*   支持自动广播：前导维度（batch dimensions）会自动广播。
*   支持批量操作：一次性计算多个矩阵乘积。
*   后端选择：编译配置决定默认偏好（YBLAS、Eigen 或 Naive），当前 dtype 或 layout 不受所选后端支持时安全回退。

### 返回值

返回 `YTensor<T, result_dim>`，其中 `result_dim = max(dim, dim1, 2)`。

### 矩阵乘法规则

假设：
- 左张量形状：`(..., m, k)`
- 右张量形状：`(..., k, n)`
- 结果形状：`(..., m, n)`

**要求**：
- 左张量的最后一个维度大小 (`k`) 必须等于右张量的倒数第二个维度大小 (`k`)
- 前面的批次维度 `(...)` 会自动广播

### 使用示例

#### 基本矩阵乘法

```cpp
#include "ytensor_single.hpp"

int main() {
    using namespace yt;
    
    // 2D × 2D
    auto a = YTensor<float, 2>::randn(3, 4);  // (3, 4)
    auto b = YTensor<float, 2>::randn(4, 5);  // (4, 5)
    auto c = a.matmul(b);                      // (3, 5)
    
    return 0;
}
```

#### 批量矩阵乘法

```cpp
// 3D × 3D
auto a = YTensor<float, 3>::randn(10, 3, 4);  // (10, 3, 4)
auto b = YTensor<float, 3>::randn(10, 4, 5);  // (10, 4, 5)
auto c = a.matmul(b);                          // (10, 3, 5)

// 执行10次矩阵乘法：
// c[i] = a[i] @ b[i]，其中 i = 0, 1, ..., 9
```

#### 广播矩阵乘法

```cpp
// 3D × 2D（广播）
auto a = YTensor<float, 3>::randn(10, 3, 4);  // (10, 3, 4)
auto b = YTensor<float, 2>::randn(4, 5);      // (4, 5)
auto c = a.matmul(b);                          // (10, 3, 5)

// b 被广播到 (10, 4, 5)
// c[i] = a[i] @ b，其中 i = 0, 1, ..., 9
```

#### 向量-矩阵乘法

```cpp
// 1D × 2D（视为行向量）
auto a = YTensor<float, 1>::randn(4);      // (4,)
auto b = YTensor<float, 2>::randn(4, 5);   // (4, 5)
auto c = a.matmul(b);                       // (1, 5)

// a 被视为 (1, 4)，结果是 (1, 5)
```

#### 矩阵-向量乘法

```cpp
// 2D × 1D（视为列向量）
auto a = YTensor<float, 2>::randn(3, 4);   // (3, 4)
auto b = YTensor<float, 1>::randn(4);      // (4,)
auto c = a.matmul(b);                       // (3, 1)

// b 被视为 (4, 1)，结果是 (3, 1)
```

#### 高维广播

```cpp
// 4D × 3D
auto a = YTensor<float, 4>::randn(2, 10, 3, 4);  // (2, 10, 3, 4)
auto b = YTensor<float, 3>::randn(10, 4, 5);     // (10, 4, 5)
auto c = a.matmul(b);                             // (2, 10, 3, 5)

// b 被广播到 (2, 10, 4, 5)
```

## masked_matmul()

`masked_matmul` 在 `matmul` 的基础上增加输出位置掩码：仅掩码为真（或谓词返回真）的位置会写入矩阵乘结果，其余位置保持为 `maskedValue`。

### 函数签名（布尔掩码）

```cpp
template <int dim1>
YTensor<T, CONSTEXPR_MAX({dim, dim1, 2})> masked_matmul(
    const YTensor<T, dim1>& other,
    const YTensor<bool, 2>& mask,
    const T& maskedValue = static_cast<T>(0),
    yt::info::MatmulBackend backend = yt::info::defaultMatmulBackend
) const;
```

### 函数签名（可调用谓词）

```cpp
template <int dim1, typename Func>
requires (!yt::utils::is_ytensor_v<std::decay_t<Func>>)
YTensor<T, CONSTEXPR_MAX({dim, dim1, 2})> masked_matmul(
    const YTensor<T, dim1>& other,
    Func&& func,
    const T& maskedValue = static_cast<T>(0),
    yt::info::MatmulBackend backend = yt::info::defaultMatmulBackend
) const;
```

### 参数说明

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `other` | `const YTensor<T, dim1>&` | 右操作数张量 |
| `mask` | `const YTensor<bool, 2>&` | 2D 布尔掩码，形状必须为 `[this.shape(-2), other.shape(-1)]` |
| `func` | `Func&&` | 谓词，签名要求 `bool(int row, int col)` |
| `maskedValue` | `const T&` | 非激活位置写入值（默认 `0`） |
| `backend` | `MatmulBackend` | 与 `matmul` 相同的后端选择策略 |

### 行为说明

- 输出先整体填充 `maskedValue`。
- 仅当 `mask(row, col) == true` 或 `func(row, col) == true` 时，计算并写入对应输出元素。
- 其余位置不参与乘加，保持 `maskedValue`。
- 广播规则与 `matmul` 一致，掩码仅作用于最后两个维度的输出平面。

### YBLAS 谓词优化（可选）

当使用 `Func` 版本并走 YBLAS 后端时，若谓词对象额外提供以下方法，可进行块级剪枝：

```cpp
bool tileAllTrue(int row0, int col0, int mr, int nr) const;
bool tileAllFalse(int row0, int col0, int mr, int nr) const;
```

这两个方法不是必须项；未提供时会回退到逐元素判断。

### 使用示例

```cpp
auto a = yt::YTensor<float, 2>::randn(4, 8);
auto b = yt::YTensor<float, 2>::randn(8, 4);

// 1) 布尔掩码版本：仅保留下三角
auto mask = yt::YTensor<bool, 2>::zeros({4, 4});
for (int i = 0; i < 4; ++i) {
    for (int j = 0; j <= i; ++j) {
        mask.at(i, j) = true;
    }
}
auto c0 = a.masked_matmul(b, mask, -1e9f);

// 2) 谓词版本：仅保留对角线
auto c1 = a.masked_matmul(
    b,
    [](int row, int col) { return row == col; },
    0.0f
);
```

## matView()

将张量的最后两个维度视为矩阵，返回矩阵视图。

### 函数签名

```cpp
YTensor<YTensor<T, 2>, std::max(1, dim - 2)> matView() const;
```

### 返回值

返回"张量的张量"，其中：
- 外层张量的维度：`max(1, dim - 2)`
- 内层张量的维度：`2`（矩阵）

### 使用场景

当需要将高维张量视为一批矩阵进行处理时：

```cpp
auto a = YTensor<float, 3>::randn(10, 3, 4);  // (10, 3, 4)

// 获取矩阵视图
auto matView = a.matView();  // YTensor<YTensor<float, 2>, 1>

// matView[i] 是一个 YTensor<float, 2>，形状 (3, 4)
auto firstMatrix = matView.at(0);  // (3, 4) 矩阵
```

### 注意事项

:::warning
**内存共享**

`matView()` 返回的视图与原张量**共享内存**：

```cpp
auto a = YTensor<float, 3>::randn(2, 3, 4);
auto mv = a.matView();

// 修改视图会影响原张量
mv.at(0).at_(1, 2) = 999.0f;
std::cout << a.at(0, 1, 2);  // 输出 999.0
```
:::

## 矩阵乘法后端

YTensor 支持三种矩阵乘法后端。编译配置决定默认偏好，调用方也可以显式传入偏好；该参数不是强制执行要求，不受支持的 dtype、layout 或构建组合会回退到可用实现。

### MatmulBackend 枚举

```cpp
enum class MatmulBackend {
    Naive = 0,  // 朴素三重循环实现
    Eigen = 1,  // Eigen 库实现
    YBLAS = 2   // YTensor 自研 BLAS 实现
};
```

### 后端特性对比

| 后端 | 依赖 | 性能 | 支持类型 | 适用场景 |
|------|------|------|---------|---------|
| **Naive** | 无 | 基准实现 | 所有类型 | 兼容、调试、非算术类型 |
| **Eigen** | Eigen 库 | Eigen 优化实现 | 算术类型 | 通用场景、跨平台 |
| **YBLAS** | 当前需要支持 AVX2+FMA 的 CPU 与编译目标 | blocked SIMD 实现 | `float`、`float16` | x86_64 矩阵计算 |

### 默认后端选择

编译时按以下优先级选择默认偏好后端：

```cpp
static constexpr MatmulBackend defaultMatmulBackend = 
#if YT_USE_YBLAS
    MatmulBackend::YBLAS
#elif YT_USE_EIGEN
    MatmulBackend::Eigen
#else
    MatmulBackend::Naive
#endif
;
```

**优先级**：YBLAS > Eigen > Naive

### 手动指定后端偏好

```cpp
auto a = YTensor<float, 2>::randn(100, 100);
auto b = YTensor<float, 2>::randn(100, 100);

// 请求 Naive 后端
auto c1 = a.matmul(b, yt::info::MatmulBackend::Naive);

// 请求 Eigen 后端；当前构建或布局不支持时会回退
auto c2 = a.matmul(b, yt::info::MatmulBackend::Eigen);

// 请求 YBLAS 后端；当前 dtype 或构建不支持时会回退
auto c3 = a.matmul(b, yt::info::MatmulBackend::YBLAS);
```

## 性能考虑

不同后端的实际性能取决于 shape、storage layout、线程数、编译器和 CPU。本文不提供脱离当前 benchmark 环境的固定 GFLOPS 或加速倍数。

### 布局支持与复制成本

矩阵乘法支持任意元素 stride，转置 view 不需要先复制为连续张量：

```cpp
auto a = YTensor<float, 2>::randn(3, 4);  // 行主序，连续存储
auto b = YTensor<float, 2>::randn(4, 5);
auto c = a.matmul(b);

auto a_t = a.transpose(0, 1);  // 非连续 view
auto b2 = YTensor<float, 2>::randn(3, 5);
auto c2 = a_t.matmul(b2);       // 无需先调用 contiguous()
```

`transpose()` 只创建 view；`contiguous()` 则分配新 storage 并复制全部元素。连续化可能改善后续访问局部性，但也会增加一次完整复制，因此不能仅凭“非连续”就判断它一定更快。

### 不同后端的布局行为

| 后端 | 左矩阵主序 | 右矩阵主序 | 性能说明 |
|------|----------|----------|----------|
| **Naive** | 任意 | 任意 | 直接按 stride 访问；局部性由具体布局决定 |
| **Eigen** | 受适配路径支持的布局 | 受适配路径支持的布局 | 性能取决于 Eigen 映射与访问模式 |
| **YBLAS** | 任意 | 任意 | 直接从源 stride packing；无需先转置整个矩阵 |

这些是布局支持合同，不代表某一布局在所有 shape 和 CPU 上都更快。具体选择见本文末尾的“最佳实践”。

## 类型要求

矩阵乘法要求类型支持加法和乘法：

```cpp
static_assert(HAVE_ADD<T> && HAVE_MUL<T>, 
              "Type must have add and mul in matmul");
```

### 支持的类型

- ✅ 所有算术类型：`float`、`double`、`int`、`int64_t` 等
- ✅ YTensor 内置低精度类型，如 `float16`、`bfloat16` 和 float8
- ✅ 自定义类型（如果实现了 `operator+` 和 `operator*`）
- ❌ 不支持加法或乘法的类型（编译错误）

### 非算术类型

非算术类型只能使用 Naive 后端：

```cpp
struct Complex {
    float real, imag;
    Complex operator+(const Complex& other) const { /*...*/ }
    Complex operator*(const Complex& other) const { /*...*/ }
};

auto a = YTensor<Complex, 2>(3, 4);
auto b = YTensor<Complex, 2>(4, 5);

// 自动使用 Naive 后端（忽略 backend 参数）
auto c = a.matmul(b);
```

## 错误处理

### 形状不匹配

```cpp
auto a = YTensor<float, 2>::randn(3, 5);  // (3, 5)
auto b = YTensor<float, 2>::randn(4, 7);  // (4, 7)

try {
    auto c = a.matmul(b);
} catch (const std::invalid_argument& e) {
    // 错误：左张量的最后一个维度 (5) != 右张量的倒数第二个维度 (4)
    std::cout << e.what() << std::endl;
}
```

**要求**：`a.shape(-1) == b.shape(-2)`

## 与 NumPy/PyTorch 的对比

### 相同点

```python
# NumPy/PyTorch
a = np.random.randn(3, 4)
b = np.random.randn(4, 5)
c = a @ b  # 或 np.matmul(a, b)
```

```cpp
// YTensor
auto a = YTensor<float, 2>::randn(3, 4);
auto b = YTensor<float, 2>::randn(4, 5);
auto c = a.matmul(b);
```

### 差异点

| 特性 | NumPy/PyTorch | YTensor |
|------|--------------|---------|
| 运算符 | `@` 或 `matmul()` | 仅 `matmul()` |
| 后端选择 | 自动（BLAS） | 可手动指定偏好，必要时回退 |
| GPU 支持 | ✅ (PyTorch) | ❌ |
| 编译时优化 | ❌ | ✅ （维度） |

## 最佳实践

### 1. 数据已有批次维度时，保留批量表达

```cpp
auto a = YTensor<float, 3>::randn(100, m, k);
auto b = YTensor<float, 3>::randn(100, k, n);

// 不推荐：拆出矩阵并逐次调度
auto a_matrices = a.matView();
auto b_matrices = b.matView();
std::vector<YTensor<float, 2>> results;
for (int i = 0; i < 100; ++i) {
    results.push_back(
        a_matrices.at(i).matmul(b_matrices.at(i))
    );
}

// 推荐：让 matmul 保留批次语义和后端调度空间
auto c = a.matmul(b);  // (100, m, n)
```

如果数据原本分散在多个独立 tensor 中，`stack()` 自身需要组合并复制数据。不要只为了“批量”无条件 stack，应比较 stack 加一次批量计算与多次独立计算的总成本。

所有 batch 共享同一个右矩阵时，直接使用广播，不要物化多份 B：

```cpp
auto a = YTensor<float, 3>::randn(100, m, k);
auto b = YTensor<float, 2>::randn(k, n);
auto c = a.matmul(b);  // b 广播到每个 batch
```

### 2. 不要在每次乘法前无条件连续化

```cpp
auto view = getTensor().transpose(0, 1);

// 单次使用：先直接计算，避免强制增加一次完整复制
auto once = view.matmul(b);

// 不推荐：在循环内反复复制同一个 view
for (const auto& weight : weights) {
    auto result = view.contiguous().matmul(weight);
}

// 如果 benchmark 证明连续布局对重复使用有收益，只复制一次
auto prepared = view.contiguous();
for (const auto& weight : weights) {
    auto result = prepared.matmul(weight);
}
```

是否值得连续化取决于 view 的 stride、矩阵 shape、后端和复用次数。两种路径都合法，区别在于复制成本能否由后续复用摊薄。

### 3. 默认使用自动偏好，只为稳定 workload 调优

```cpp
// 通常从默认偏好开始
auto c = a.matmul(b);

// 只有代表性 benchmark 证明更合适时才固定偏好
auto tuned = a.matmul(
    b,
    yt::info::MatmulBackend::Eigen
);
```

不要使用未经测量的固定阈值，例如仅凭 `m*n*k < 1000` 就强制选择 Naive。后端开销还取决于 batch、stride、dtype、线程数、编译器和 CPU。
