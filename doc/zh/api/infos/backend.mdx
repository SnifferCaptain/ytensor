# 后端系统

本文档介绍 `yt::info` 命名空间中的矩阵乘法后端配置。

## MatmulBackend 枚举

```cpp
enum class MatmulBackend {
    Naive = 0,  // 朴素实现，无依赖
    Eigen = 1,  // Eigen 库实现
    YBLAS = 2   // YTensor 自研 BLAS 实现
};
```

## 默认后端

```cpp
static constexpr MatmulBackend defaultMatmulBackend = 
#if YT_USE_YBLAS
    MatmulBackend::YBLAS
#elif YT_USE_EIGEN
    MatmulBackend::Eigen
#else
    MatmulBackend::Naive
#endif
;
```

优先级：YBLAS > Eigen > Naive

## 编译宏

| 宏 | 说明 |
| --- | --- |
| `YT_USE_EIGEN` | 启用 Eigen 后端 |
| `YT_USE_YBLAS` | 启用 YBLAS 后端 |
| `YT_USE_AVX2` | 启用当前 YBLAS 使用的 AVX2+FMA 物理内核 |

YBLAS 当前只有 AVX2+FMA 物理内核，因此 `YT_USE_YBLAS` 默认跟随 `YT_USE_AVX2`。
`YT_USE_AVX2` 根据编译器的 AVX2/FMA feature macro 自动检测；可以显式定义为 `0` 以禁用，
但不能只定义为 `1` 而不启用对应编译选项。

`MatmulBackend` 参数表示后端偏好。当前 dtype 或构建配置不受指定后端支持时，会回退到可用实现。
