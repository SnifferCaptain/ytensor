# 后端选择

本指南帮助你选择最适合的计算后端。

## 可用后端

YTensor 的矩阵乘法支持多个后端：

| 后端 | 枚举值 | 依赖 | 适用场景 |
| --- | --- | --- | --- |
| Naive | `MatmulBackend::Naive` | 无 | 兼容性优先、调试 |
| Eigen | `MatmulBackend::Eigen` | Eigen3 | 一般高性能计算 |
| YBLAS | `MatmulBackend::YBLAS` | 当前需要支持 AVX2+FMA 的 CPU 与编译目标 | YTensor 自研的 FP32/FP16 矩阵运算 |

`backend` 参数表示后端偏好，而不是必须使用的实现。如果指定后端不支持当前 dtype 或构建配置，YTensor 会回退到可用实现。布局和 dtype 行为见 [YTensor::matmul](../YTensor/math/matmul.mdx)。

---

## 自动选择

默认后端根据编译时宏自动选择，优先级：**YBLAS > Eigen > Naive**

```cpp
// ytensor_infos.hpp 中的定义
static constexpr MatmulBackend defaultMatmulBackend = 
#if YT_USE_YBLAS
    MatmulBackend::YBLAS
#elif YT_USE_EIGEN
    MatmulBackend::Eigen
#else
    MatmulBackend::Naive
#endif
;
```

## 编译配置

### 启用 Eigen

```cmake
# CMakeLists.txt
find_package(Eigen3 REQUIRED)
target_link_libraries(your_target Eigen3::Eigen)
```

Eigen 会被自动检测：
```cpp
#if __has_include(<Eigen/Core>)
    #define YT_USE_EIGEN 1
#endif
```

### 启用 YBLAS

```cmake
# CMakeLists.txt
target_compile_options(your_target PRIVATE -mavx2 -mfma)
```

YBLAS 当前只有 AVX2+FMA 物理内核。`YT_USE_AVX2` 根据编译器 feature macro 自动检测，
`YT_USE_YBLAS` 默认跟随该检测结果。单独定义 `YT_USE_AVX2=1` 不会启用 CPU 指令；如果编译目标
没有同时启用 AVX2 和 FMA，YTensor 会拒绝该配置。

如需保留 AVX2 编译目标但禁用自研后端，可在包含 YTensor 前定义 `YT_USE_YBLAS=0`。如需同时
禁用 AVX2 物理内核，则定义 `YT_USE_AVX2=0`。

## 检查当前后端

```cpp
#include "ytensor_infos.hpp"

void check_backend() {
    #if YT_USE_YBLAS
        std::cout << "Using YBLAS backend" << std::endl;
    #elif YT_USE_EIGEN
        std::cout << "Using Eigen backend" << std::endl;
    #else
        std::cout << "Using Naive backend" << std::endl;
    #endif
}
```
