# YTensorIO

`yt::io::YTensorIO` 用于读取 `.yt` 文件，并以事务方式写入张量。

## 打开与提交

```cpp
yt::io::YTensorIO io;
if (!io.open("model.yt", yt::io::Write)) return false;
if (!io.save(tensor, "weight")) return false; // 仅完成暂存
if (!io.close()) return false;                // 持久化提交结果
```

```cpp
bool open(const std::string& fileName, int fileMode = yt::io::Read);
bool close();
```

模式包括 `yt::io::Read`、`yt::io::Write` 和 `yt::io::Append`。写事务在 `close()` 完整写入并flush同目录临时文件之前不会替换原目标。不能直接rename覆盖已有文件的标准库实现会使用同目录backup/restore事务。暂存或可恢复的提交失败会使 `close()` 返回 `false` 并保留此前已提交文件。析构函数为 `noexcept`，无法报告提交结果；需要确认持久化成功时必须显式调用 `close()`。

## 保存

```cpp
bool save(const yt::YTensorBase& tensor, const std::string& name);

template<typename T, int dim>
bool save(const yt::YTensor<T, dim>& tensor, const std::string& name);
```

`save()` 序列化并暂存一个 Strided 张量。返回 `true` 只表示暂存成功，持久化结果由 `close()` 返回。同名记录会被新的暂存内容替换。压缩方式由全局 `yt::io::compressMethod` 控制。

非POD dtype必须注册 `serialize` 和 `deserialize` 回调。Map payload支持变长序列化值，不受 `sizeof(T)` 限制。

## 加载

```cpp
bool load(yt::YTensorBase& tensor, const std::string& name = "");

template<typename T, int dim>
bool load(yt::YTensor<T, dim>& tensor, const std::string& name = "");
```

加载会先验证metadata、文件范围、payload大小、dtype生命周期和序列化数据，全部成功后才替换目标。失败返回 `false` 且目标保持不变。Typed load还会验证dtype和rank。

## 便利函数

```cpp
bool saveTensorBase(const std::string& fileName, const YTensorBase& tensor,
                    const std::string& name = "");
bool loadTensorBase(const std::string& fileName, YTensorBase& tensor,
                    const std::string& name = "");

template<typename T, int dim>
bool saveTensor(const std::string& fileName, const YTensor<T, dim>& tensor,
                const std::string& name = "");
template<typename T, int dim>
bool loadTensor(const std::string& fileName, YTensor<T, dim>& tensor,
                const std::string& name = "");
```

保存便利函数的bool结果覆盖 `open()`、暂存和 `close()` 整个事务。
